A repo for all of the development stuff involving my Sonic CD special stage recreation.
If you wish to expand upon this, feel free to as long as you credit SEGA for creating Sonic CD and its assets, as well as me (LittleBlueBox) for making the base script.
Everything except the map development files are meant to go into a mod folder (or new dlc folder)
Map development files are meant to go into the sdk_content/maps/ folder. the sonic_cd maps folder is specifically meant to go into sdk_content/maps/instances/
